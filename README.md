# Korp - Sistema de Emissão de Notas Fiscais

Aplicação desenvolvida para o teste técnico da Korp.

## Objetivo

Desenvolver um sistema para cadastro de produtos, controle de estoque e emissão de notas fiscais.

## Tecnologias

### Front-end

- Angular
- TypeScript
- HTML
- SCSS
- RxJS

### Back-end

- C#
- ASP.NET Core Web API
- Entity Framework Core

### Banco de dados e infraestrutura

- PostgreSQL
- Docker
- Docker Compose

## Arquitetura

O sistema será composto por dois microsserviços:

- Serviço de Estoque
- Serviço de Faturamento
